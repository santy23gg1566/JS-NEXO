Seguridad de tu panel

La contraseña no está en el código HTML. Se comprueba en Netlify Functions y la sesión utiliza una cookie HttpOnly. Para cambiarla, entra a las variables de entorno en Netlify y realiza un nuevo despliegue. La protección del panel no sustituye una cuenta con autenticación multifactor.

07 / HELP

Una tienda. Sin complicaciones.

Cómo trabajar desde este panel.

Para añadir un producto

  1. Abre Productos → Nuevo producto.
  2. Escribe nombre, categoría y descripción. Los precios y unidades son opcionales hasta confirmarlos.
  3. Selecciona una foto y pulsa Subir imagen.
  4. Pulsa Guardar en borrador dentro del formulario.
  5. Finalmente pulsa PUBLICAR CAMBIOS arriba.

Para editar textos o redes

  1. Entra en Contenido web o Identidad y redes.
  2. Cambia lo que necesites; verás el estado «Cambios sin publicar».
  3. Haz clic en PUBLICAR CAMBIOS.
  4. Abre la tienda y recarga para ver los cambios.
